# CricketGPT — Match Services

## Responsibility
Retrieves and constructs structured match data from Supabase PostgreSQL.

### Core Capabilities
- Fetch complete match details by `match_id` (teams, venue, toss, outcome, awards).
- Assemble full scorecards: batting cards, bowling figures, fall of wickets, partnerships.
- Filter matches by season, team, date range, venue, and outcome type.
- Retrieve ball-by-ball delivery feeds with over-by-over progression.
