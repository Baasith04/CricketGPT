# CricketGPT — Player Services

## Responsibility
Manages player profile lookups and career-level statistics aggregation.

### Core Capabilities
- Look up canonical player records by `player_id` (Cricsheet hex ID) or search by name.
- Aggregate IPL career batting statistics (total runs, 50s, 100s, 4s, 6s, strike rate, average).
- Aggregate IPL career bowling statistics (overs, maidens, runs conceded, wickets, economy).
- Compute head-to-head player matchups (e.g. Virat Kohli vs Jasprit Bumrah: balls faced, runs, dismissals).
- Support player comparisons across seasons or specific phases (Powerplay vs Death overs).
