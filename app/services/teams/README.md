# CricketGPT — Team Services

## Responsibility
Provides franchise-level statistics, historical performance, and rivalry analysis.

### Core Capabilities
- Retrieve canonical franchise details and map historical team aliases (e.g. Delhi Daredevils -> Delhi Capitals).
- Calculate overall franchise records (total matches, wins, losses, win percentage, ties).
- Head-to-head records between any two franchises (e.g. CSK vs MI all-time).
- Season-by-season performance and title summaries.
- Home vs Away venue performance metrics.
